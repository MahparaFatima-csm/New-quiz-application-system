# New Quiz Application System - Java OOP

A simple and interactive console-based Quiz Application developed in Java using Object-Oriented Programming (OOP) concepts.

This project demonstrates the use of classes, inheritance, and objects.

## ✨ Features

- **OOPs Based:** Proper use of Classes (Main, Question, MCQQuestion)
- **Inheritance:** MCQQuestion class extends Question class
- **Interactive Quiz:** Takes student name as input and greets the user
- **5 MCQ Questions:** Covers basic OOP concepts (Java, Inheritance, Object, Encapsulation, main method)
- **Instant Feedback:** Shows "Correct Answer!" immediately after each answer
- **Result System:** Displays final result with Student Name, Total Questions, Score (5/5), and Percentage (100%)

## 💻 How to Run

1. Go to folder: `cd QuizApplicationSystem`
2. Compile the program: `javac Main.java`
3. Run the program: `java Main`
